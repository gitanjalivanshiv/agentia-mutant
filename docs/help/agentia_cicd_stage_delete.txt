Delete a Copado stage

USAGE
  $ agentia cicd stage delete ID [--json] [-y]

ARGUMENTS
  ID  Stage ID

FLAGS
  -y, --yes  Confirm deletion without prompting

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Delete a Copado stage

EXAMPLES
  $ agentia cicd stage delete <stage-id>

  $ agentia cicd stage delete <stage-id> --yes --json
