Alias of cicd work publish. Publishes the current feature/<lastWorkItem> branch and registers commits with Copado. Prefer: agentia cicd work publish.

USAGE
  $ agentia cicd work push [--json] [--full-metadata <value>] [--permissions
    <value>] [--skip-nested-metadata-detection]

FLAGS
  --full-metadata=<value>
      Comma-separated Type:Name metadata such as
      Profile:Sales_User,PermissionSet:Sales_Onboarding. Allowed types: Profile,
      PermissionSet, MutingPermissionSet, CustomObject, CustomObjectTranslation.
      Added for this publish and sent as headless push fullMetadata corrections.
      The named metadata is committed as a complete file, so it is never
      decomposed into nested metadata. Not stored.

  --permissions=<value>
      Comma-separated type-prefixed metadata such as
      CustomField:Account.SLA__c,ApexClass:AccountService, added for this publish
      and sent as headless push RetrieveOnly corrections. Not stored.

  --skip-nested-metadata-detection
      Do not detect the nested metadata changed across the branch (also
      configurable via skipNestedMetadataDetection in .agentia/config.json or
      .agentia/config.user.json)

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Alias of cicd work publish. Publishes the current feature/<lastWorkItem>
  branch and registers commits with Copado. Prefer: agentia cicd work publish.

EXAMPLES
  $ agentia cicd work publish

  $ agentia cicd work push

  $ agentia cicd work push --skip-nested-metadata-detection

  $ agentia cicd work push --json
