List stage connections for a Copado pipeline

USAGE
  $ agentia cicd pipeline stage-connection list --pipeline-id <value> [--json]

FLAGS
  --pipeline-id=<value>  (required) Pipeline ID whose stage connections should
                         be listed

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  List stage connections for a Copado pipeline

EXAMPLES
  $ agentia cicd pipeline stage-connection list --pipeline-id <pipeline-id>

  $ agentia cicd pipeline stage-connection list --pipeline-id <pipeline-id> --json
