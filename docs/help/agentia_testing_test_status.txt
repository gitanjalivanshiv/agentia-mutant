List Copado Robotic Testing run status

USAGE
  $ agentia testing test status -p <value> [--json] [--job <value>]
    [--result-size compact] [--status
    aborted|executing|failed|finished|queued|succeeded]

FLAGS
  -p, --project=<value>       (required) CRT project ID.
      --job=<value>           Limit status to one CRT job/test ID.
      --result-size=<option>  [default: compact] CRT build result size.
                              <options: compact>
      --status=<option>       Build status filter.
                              <options: aborted|executing|failed|finished|queued
                              |succeeded>

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  List Copado Robotic Testing run status

EXAMPLES
  $ agentia testing test status --project <project-id>

  $ agentia testing test status --project <project-id> --job <job-id> --status executing --json
