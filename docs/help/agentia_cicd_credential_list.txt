List credentials for a Copado environment

USAGE
  $ agentia cicd credential list --environmentid <value> [--json]

FLAGS
  --environmentid=<value>  (required) Copado environment ID

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  List credentials for a Copado environment

EXAMPLES
  $ agentia cicd credential list --environmentid <environment-id>

  $ agentia cicd credential list --environmentid "Dev Sandbox"

  $ agentia cicd credential list --environmentid <environment-id> --json
