Save a bounded CRT live browser screenshot to an explicit file

USAGE
  $ agentia testing live screenshot [JOB-ID] -p <value> -o <value> [--json]
    [--session-id <value>]

ARGUMENTS
  [JOB-ID]  Optional CRT job/test ID guard.

FLAGS
  -o, --output=<value>      (required) Explicit screenshot output path.
  -p, --project=<value>     (required) CRT project ID.
      --session-id=<value>  Guard that must match the locally active CRT live
                            session.

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Save a bounded CRT live browser screenshot to an explicit file

EXAMPLES
  $ agentia testing live screenshot --project <project-id> --output screenshot.png
