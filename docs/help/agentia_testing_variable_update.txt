Update a Copado Robotic Testing variable/secret

USAGE
  $ agentia testing variable update ID -p <value> [--json] [--description <value>]
    [--key <value>] [--not-sensitive] [--sensitive] [--type
    clp|config|dataset|secret] [--no-trim | --trim] [--value <value> |
    --value-file <value> | --value-stdin]

ARGUMENTS
  ID  CRT variable/secret ID.

FLAGS
  -p, --project=<value>      (required) CRT project ID.
      --description=<value>  Variable description.
      --key=<value>          Variable key.
      --no-trim              Preserve leading and trailing whitespace in the
                             supplied value.
      --not-sensitive        Mark the variable as not sensitive.
      --sensitive            Mark the variable as sensitive.
      --trim                 Trim leading and trailing whitespace (the default
                             policy).
      --type=<option>        CRT variable type.
                             <options: clp|config|dataset|secret>
      --value=<value>        Value supplied directly. Prefer file/stdin for
                             sensitive values.
      --value-file=<value>   Read the value from a bounded regular file.
      --value-stdin          Read the value from stdin.

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Update a Copado Robotic Testing variable/secret

EXAMPLES
  $ agentia testing variable update <variable-id> --project <project-id> --value https://example.com

  $ agentia testing variable update <variable-id> --project <project-id> --not-sensitive --json
