Create a Copado environment credential

USAGE
  $ agentia cicd credential create --environmentid <value> --name <value> [--json]
    [--default]

FLAGS
  --[no-]default           Mark this credential as the environment default
  --environmentid=<value>  (required) Copado environment ID
  --name=<value>           (required) Credential name

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Create a Copado environment credential

EXAMPLES
  $ agentia cicd credential create --environmentid <environment-id> --name "CI User"

  $ agentia cicd credential create --environmentid <environment-id> --name "CI User" --default

  $ agentia cicd credential create --environmentid <environment-id> --name "CI User" --json
