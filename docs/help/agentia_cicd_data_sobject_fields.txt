Describe fields for an sObject via a credential

USAGE
  $ agentia cicd data sobject fields SOBJECTAPINAME --credential-id <value>
  [--json]

ARGUMENTS
  SOBJECTAPINAME  sObject API name

FLAGS
  --credential-id=<value>  (required) Org credential Id

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Describe fields for an sObject via a credential

EXAMPLES
  $ agentia cicd data sobject fields Account --credential-id a0Y...

  $ agentia cicd data sobject fields Account --credential-id a0Y... --json
