Update a pipeline stage connection

USAGE
  $ agentia cicd pipeline stage-connection update ID --pipeline-id <value> [--json]
    [--next-pipeline-stage-connection-id <value>] [--stage-id <value>]

ARGUMENTS
  ID  Pipeline stage connection ID

FLAGS
  --next-pipeline-stage-connection-id=<value>  Next pipeline stage connection ID
  --pipeline-id=<value>                        (required) Pipeline ID
  --stage-id=<value>                           Stage ID

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Update a pipeline stage connection

EXAMPLES
  $ agentia cicd pipeline stage-connection update connection-1 --pipeline-id pipeline-1 --next-pipeline-stage-connection-id connection-2
