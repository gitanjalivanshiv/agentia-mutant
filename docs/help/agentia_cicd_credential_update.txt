Update a Copado environment credential by ID

USAGE
  $ agentia cicd credential update ID --environmentid <value> [--json] [--default]
    [--name <value>]

ARGUMENTS
  ID  Copado credential ID

FLAGS
  --[no-]default           Mark this credential as the environment default
  --environmentid=<value>  (required) Copado environment ID
  --name=<value>           Credential name

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Update a Copado environment credential by ID

EXAMPLES
  $ agentia cicd credential update <credential-id> --environmentid <environment-id> --name "CI User"

  $ agentia cicd credential update <credential-id> --environmentid <environment-id> --default

  $ agentia cicd credential update <credential-id> --environmentid <environment-id> --no-default --json
