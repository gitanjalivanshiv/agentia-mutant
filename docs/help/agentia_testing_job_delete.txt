Delete a Copado Robotic Testing job/test

USAGE
  $ agentia testing job delete ID -p <value> [--json] [-y]

ARGUMENTS
  ID  CRT job/test ID.

FLAGS
  -p, --project=<value>  (required) CRT project ID.
  -y, --yes              Skip the destructive confirmation prompt.

GLOBAL FLAGS
  --json  Format output as json.

DESCRIPTION
  Delete a Copado Robotic Testing job/test

EXAMPLES
  $ agentia testing job delete <job-id> --project <project-id> --yes

  $ agentia testing job delete <job-id> --project <project-id> --yes --json
